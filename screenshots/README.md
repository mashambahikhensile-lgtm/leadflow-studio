# LeadFlow Studio — Portfolio Screenshots

These screenshots document the user interface and workflow of LeadFlow Studio, a self-initiated portfolio project by Mash Web Studio.

All sample lead information is fictional. The project demonstrates a lead intake form, input validation, lead storage, an administrative dashboard, and an optional webhook integration.

## Screenshots

### 1. Public Homepage
The landing page introduces LeadFlow Studio and explains how the lead intake workflow operates.

### 2. Workflow Explanation
An overview of the three main stages: capturing an enquiry, validating the information, and managing follow-up.

### 3. Successful Enquiry Submission
Demonstrates the success message displayed after a valid enquiry is submitted.

### 4. Admin Dashboard
Shows the administrative interface for reviewing enquiries, viewing lead statistics, and managing records.

### 5. Lead Management
Demonstrates the lead list and the available status-management controls.

### 6. Webhook Integration
Supporting technical evidence showing a successful request reaching a webhook testing endpoint.
